Cloud Firestore Collections

Defined in firebase-blueprint.json and enforced in firestore.rules
Collection Path Entity Purpose & Access Model
/users/{userId} UserProfile Public colleague directory, live availability status, online flag, and lastSeen timestamp; owner-writable.
/users/{userId}/contacts/{contactId} ContactEntry Private bookmarked Friends & Colleagues list scoped strictly to the owning user.
/users/{userId}/settings/privacy PrivacySettings Read receipts and last-seen visibility toggles, readable/writable only by userId.
/users/{userId}/blocked/{blockedId} BlockedUser Blocked contact records scoped to the owning user.
/chats/{chatId} & /messages/{messageId} Chat, Message Direct and group conversations with memberIds gating, typing flags, reactions, voice clips, media, and read receipts.
/chatRooms/{roomId} ChatRoom Departmental group rooms with memberIds, adminIds, and protected createdBy admin delegation.
/statuses/{statusId} StatusItem 24-hour ephemeral text, photo, and video stories with viewer tracking.
/channels/{channelId} & /posts/{postId} Channel, ChannelPost Flexible public or invite-only broadcast channels with follower posting settings and verified admin promotion.
/communities/{communityId} Community Umbrella communities linking subgroup rooms with creator-protected admin promotion.
/reports/{reportId} Report Abuse and compliance reports restricted to authenticated submission.

Publishing This Documentation on GitHub Pages

Serve /docs directly via GitHub repository settings

Enable GitHub Pages

  1. Push the repository (including the docs/ directory) to GitHub on main or master.
  2. Open Settings → Pages in SAT-Limited-Organization/SAT-Messenger.
  3. Under Build and deployment → Source, choose Deploy from a branch.
  4. Select branch main (or master) and folder /docs, then click Save.
  5. Your site goes live at https://sat-limited-organization.github.io/SAT-Messenger/.
