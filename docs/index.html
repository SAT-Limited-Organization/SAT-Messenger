Sideloading & Obtainium Auto-Updates

  • GitHub Releases (Direct APK): Download sat-messenger-release.apk (or sat-messenger-debug.apk) on Android, tap the file, and allow "Install unknown apps" for your browser or file manager when prompted.
  • Obtainium Auto-Updates: Add https://github.com/SAT-Limited-Organization/SAT-Messenger in Obtainium to track versioned releases (v4.2.07.11.2026.14.5.1, etc.) and install updates with one tap.

Verify Download Integrity & In-App Check

Verify any downloaded APK or App Bundle against the release's SHA256SUMS.txt manifest:

sha256sum -c SHA256SUMS.txt

You can also check for new GitHub Releases or confirm your installed version anytime inside the in-app Profile & Settings screen.

Key Features

Complete feature overview from README & User Manual

Authentication & Onboarding Zero-Trust

  • Google Identity Sign-In: Authenticate securely with Google (Jetpack CredentialManager + Firebase Auth) with automatic Cloud Firestore profile provisioning.
  • Pre-Auth & In-App Manual: A synchronized App Manual & User Guide is available directly on the Sign-In / Registration screen as well as inside the authenticated app, searchable by feature and category.

Contacts, Find Friends & Real-Time Availability Live Sync

  • Find Friends via Device Contacts: Match saved contacts (ContactsContract) by email or phone number against registered SAT Messenger accounts.
  • Live Availability Statuses: Broadcast and view Available, Busy, Away, In a Meeting, Do Not Disturb, and Offline (with relative Last seen timestamps).
  • Two-Way Friend Requests & 5-Field Search: Send/accept friend requests and search by Registered Name, Email, Phone Number, Primary @username, or Secondary @username.

SAT Limited AI Assistant AI + Search

  • Powered by Firebase AI Logic & App Check: Conversational assistant built directly into the Chats screen with multi-turn context, streaming answers, and zero hardcoded API keys.
  • Model Modes & Multimodal Input: Switch between Smart (gemini-3.8-flash), Fast (gemini-3.5-flash-lite), and Reasoning (gemini-4-argon), and attach photos via Android Photo Picker for visual Q&A.
  • Google Search Grounding: Toggle live Google Search grounding to enrich answers with web queries and clickable citation source links.

Messaging, Reactions, Voice & Media Real-Time

  • 1-on-1 & Group Chats: Live typing indicators, read receipts, unread badges, quoted replies, and clear sender attribution.
  • Emoji Reactions: Long-press any message to add or toggle reactions (👍, ❤️, 😂, 😮, 😢, 🙏, 🔥, 🎉, 👏, 🚀, plus extended emoji picker).
  • Voice Recording & Playback: Record inline audio clips up to 90 seconds (RECORD_AUDIO), preview before sending, and play/scrub inside chat bubbles.
  • Photo, Video & Document Sharing: Zero-permission Photo Picker (ImageAndVideo), document composer, full-screen image viewer, inline VideoView player, and chat management controls.

Icons, Admin Promotion, Channels, Communities & Status Governance

  • Profile, Group, Channel & Community Icons: Customize or remove Profile photos, Group Room icons, Channel icons, and Community icons using Android's zero-permission Photo Picker.
  • Admin Promotion (Groups, Channels & Communities): Creators and existing admins can promote or dismiss fellow members as Admins, backed by Cloud Firestore security rules that protect creators.
  • Flexible Broadcast Channels: Public or invite-only channels with custom categories, follower posting toggles, reactions, and admin management.
  • Communities & Invite Links: Group departmental rooms and an announcements hub under communities; share/reset deep links (satmessenger://invite/<code> and https://satmessenger.app/invite/<code>).
  • 24-Hour Status Updates: Share text, photos, or short videos as stories with viewer tracking and inline replies.

Phone Notification Center Alerts Android 13+

  • Dedicated Channels: Direct & Group Messages and Channels & Alerts channels in Android Notification Center.
  • Runtime Permission & Deep Routing: Requests POST_NOTIFICATIONS cleanly on Android 13+, posts unread alerts when chats are closed, and navigates straight to the target chat on tap.

Automated GitHub CI/CD & Local Build

Workflow: .github/workflows/release-apk.yml

GitHub Repository Secrets

Configure under Settings → Secrets and variables → Actions:

  • GOOGLE_SERVICES_JSON: Full JSON (or base64) contents of app/google-services.json.
  • DEBUG_KEYSTORE_BASE64: Base64 contents of debug.keystore.base64 (for Google Sign-In in QA builds).
  • RELEASE_KEYSTORE_BASE64: Base64-encoded .jks keystore containing key alias upload.
  • STORE_PASSWORD & KEY_PASSWORD: Passwords for your upload keystore and alias upload.
keytool -genkeypair -v -keystore my-upload-key.jks -alias upload \
  -keyalg RSA -keysize 2048 -validity 10000
base64 -w 0 my-upload-key.jks

Build Locally via Gradle

Run these commands from the repository root:

# Restore/verify debug signing keystore if needed
bash scripts/ensure-debug-keystore.sh

# Build universal debug APK -> app/build/outputs/apk/debug/app-debug.apk
gradle :app:assembleDebug

# Build signed release APK & Play AAB (requires KEYSTORE_PATH, STORE_PASSWORD, KEY_PASSWORD)
gradle :app:assembleRelease :app:bundleRelease

Verification & Configuration Notes

Firestore security tests, Robolectric UI suite, and environment safety

Run Full Test Suite

# Run Firestore rules tests and Android debug unit tests together
firebase emulators:exec --only auth,firestore --project demo-no-project \
  "node --test firestore.test.js && gradle :app:testDebugUnitTest"

Configuration Notes

  • Firebase: Client configuration is stored in app/google-services.json (project sat-limited). Deploy rule updates with firebase deploy --only firestore:rules.
  • Release Signing: Configure KEYSTORE_PATH (default my-upload-key.jks, key alias upload), STORE_PASSWORD, and KEY_PASSWORD when building a signed release APK/AAB.
  • Secrets: Environment keys belong in AI Studio's Secrets panel (mapped via .env.example), never hardcoded in source files.
